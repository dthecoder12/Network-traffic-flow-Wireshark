# Wireshark Network Traffic Analysis Lab

## Overview
This project demonstrates basic network traffic analysis using Wireshark in a virtual machine environment (Parrot OS). The goal was to capture and inspect ICMP and DNS packets generated through terminal commands.

## Objectives
- Capture live network packets using Wireshark
- Generate traffic using terminal commands
- Analyze ICMP
